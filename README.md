# Concept Cards

Repositorio de documentación para estudiar y consultar conceptos de desarrollo de software mediante fichas breves en Markdown.

Cada ficha explica un tema de forma autocontenida: define el concepto, resume sus ideas clave y, cuando corresponde, incluye ejemplos, ventajas, desventajas, casos de uso y consideraciones de complejidad.

## Contenido

La documentación está organizada por áreas:

- `programacion/`: conceptos fundamentales, algoritmos, estructuras de datos, arquitectura de código, bases de datos, Git, Java, TypeScript, Angular, Spring Boot y patrones de diseño.
- `guias/`: guías prácticas de preparación y configuración del entorno de desarrollo.

## Uso

Explora las carpetas temáticas y abre los archivos Markdown de cada concepto. Las fichas sirven como material de repaso rápido y como punto de partida para profundizar en cada tema.
